# Host_Security


🔐 Lab 9.6: Host Security (Zybooks)
This lab focuses on strengthening the security of host systems by minimizing attack surfaces and enforcing system protection policies. The exercises walk through practical steps for host hardening on a Windows Server 2022 virtual machine.

🧠 Learning Objectives
--Disable unnecessary host services

--Enforce password complexity and lockout policies

--Disable inactive user accounts

--Encrypt local drives using BitLocker

--Set up virus and threat protection

🖥️ Environment
--VM Used: ZyWin01 (Windows Server 2022)

✅ Tasks Completed
1) Disabled vulnerable or unused host services

2) Applied strong password and lockout policies

3) Deactivated the default guest account

4) Enabled full-disk encryption with BitLocker

5) Configured antivirus and real-time protection settings
